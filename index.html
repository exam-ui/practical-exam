⚙ Backend Setup (one-time, done by admin/IT)

This portal stores every upload — student lists, time table, examiner/subject/co-examiner lists — in a Google Sheet and a Google Drive folder that you control, using a small free Google Apps Script as the connector. Do this once:

  1. Create a new Google Sheet (any name).
  2. In the Sheet, open Extensions → Apps Script.
  3. Delete the starter code, paste in the script below (use "Copy Script" to copy it), and save.
  4. Deploy → New deployment → type: Web app. Set "Execute as: Me" and "Who has access: Anyone". Click Deploy and authorize the permissions it asks for.
  5. Copy the resulting Web app URL (it ends in /exec).
  6. Open this portal's HTML file in a text editor, find const GOOGLE_SCRIPT_URL = ''; near the top of the script, paste the URL between the quotes, save, and re-share/re-host this updated file.

Everyone who opens this portal reads and writes the same Google Sheet / Drive folder — no separate accounts or logins needed for students or staff.
